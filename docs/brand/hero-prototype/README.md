# Hero prototype (gate G5, approved option H4A)

Working prototype of the averrow.com hero chosen at gate G5: H1's headline, copy and full-size operation graph, auto-playing through H3's four steps (domain found, infrastructure linked, actor attributed, takedown filed), with a step bar, click-to-jump and a pause button.

- `h4a.html` — the approved version (A, auto-play). Open it directly in a browser.
- `h4b.html` — the scroll-driven alternative (B), kept for reference.
- `src/` — the template + script sources the pages were built from (`build4.js` inlines them).

Prototype only. Phase 5 rebuilds this inside `packages/averrow-marketing` against the real tokens; measured cost was speed 100, LCP 0.8 s, ~4.5 KB JS after paint.
